Core Architecture & Low-Spec CPU Optimizations:

• Bounded Tiled Matrix Engine (tile_size=64): Instead of passing heavy, blocking matrix multiplications to the CPU registers all at once, the core dynamically slices multi-modal workloads into micro-tiles. This keeps memory allocation strictly predictable and safe.
• Vectorized Activation Micro-Layers: To prevent standard Python interpreter bottlenecks, I utilized NumPy to deploy a vectorized hyperbolic tangent (np.tanh) approximation layer that closely mirrors transformer GELU activation structures natively on host CPU threads.
• Active Real-Time Memory Shield: The engine hooks straight into the host OS memory tables, continuously evaluating telemetry data against a user-defined threshold to gracefully isolate heavy token generation before it causes system lag.
• Decoupled Lazy Loading: The Janus-Pro adapter maps model weights on-demand. It handles static spatial downscaling for vision tasks and strictly enforces key-value token caching (use_cache=True) to completely eradicate redundant CPU processing cycles.
Let's be realistic: it's not going to set speed records like dedicated A100 or RTX silicon. Synthesizing a comprehensive 576-token image can take anywhere between 2 to 5 minutes depending on your baseline CPU clock speed. But this isn't a pure benchmark sprint—this is hardware democratization. It proves that with smart software orchestration, simple consumer silicon can reliably execute multi-modal AI tasks that normally demand massive cloud servers.
